# idealos agent instructions

These add to, and where they conflict override, `~/projects/AGENTS.md`.

## Branches

Work directly on `main`. Much of the codebase is still changing and one agent is
writing the code, so feature branches add overhead without benefit. Create a
branch only for speculative work that will need to live for a while.

Everything else about git still applies: ask before committing or pushing unless
told otherwise, and never discard uncommitted changes. Revisit this rule when
other people start contributing.
